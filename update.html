Mettre à jour l’extension

Télécharge la dernière archive ZIP publiée sur GitHub, extrais-la, puis recharge le dossier de l’extension dans Chrome.

Étapes dans Chrome

  1. Télécharge l’archive avec le bouton ci-dessus.
  2. Dans l’Explorateur Windows, fais un clic droit sur DiscordProtect.zip, choisis Extraire tout…, puis mémorise l’emplacement du dossier extrait.
  3. Ouvre chrome://extensions et active le Mode développeur.
  4. Si tu as remplacé les fichiers dans le même dossier que l’extension chargée, clique sur Recharger sur sa carte. Si tu as extrait le ZIP dans un nouvel emplacement, supprime l’ancienne carte, clique sur Charger l’extension non empaquetée et sélectionne le dossier extrait qui contient directement manifest.json.
  5. Vérifie que la version affichée dans la carte de l’extension est à jour, puis recharge les onglets ouverts pour appliquer les changements aux pages.

Important : ne sélectionne pas le fichier ZIP lui-même : Chrome a besoin du dossier extrait qui contient manifest.json. Une extension installée depuis le Chrome Web Store se met à jour via le Store et ne se remplace pas en chargeant ce ZIP.

Comment les nouvelles versions sont publiées

Quand une mise à jour de l’extension est envoyée sur la branche main du dépôt, GitHub Actions prépare le ZIP et le publie dans la dernière release. Cette page du site est hébergée séparément par GitHub Pages. Le ZIP ne s’installe pas silencieusement : il faut suivre les étapes ci-dessus pour une extension chargée en mode développeur.
