COMMENT LE TEST FONCTIONNE

Trois contrôles indépendants

Le résultat dépend des fonctions du bloqueur et des règles réseau de votre configuration. Un VPN ou un filtre DNS ne remplace pas les filtres cosmétiques.

01 / DOM

Filtres cosmétiques

Deux faux emplacements publicitaires, dont un ajouté après le chargement, servent à vérifier si le contenu est masqué ou retiré.

02 / SCRIPTS

Chargement des scripts

Des fichiers leurres nommés ads.js et pagead.js vérifient si les règles du navigateur empêchent leur exécution.

03 / DNS

Blocage des hôtes

Des domaines de publicité, d’analytics, de réseaux sociaux et de télémétrie mesurent le filtrage par l’extension, le DNS ou le réseau.

LIRE LE SCORE AVEC CONTEXTE

Un filtre DNS seul ne fait pas le même travail qu’une extension.

Pi-hole, AdGuard Home, NextDNS et les autres résolveurs filtrent les noms d’hôtes. Ils ne peuvent pas retirer un élément déjà dessiné dans la page ni empêcher à eux seuls un script de s’exécuter dans le navigateur.

Le guide AdBlockTest indique qu’un score DNS seul autour de 40 à 60 % peut être normal. Pour évaluer ce type de configuration, regardez surtout la catégorie des hôtes plutôt que le score global.

Un portail de blocage renvoyé à la place d’un domaine peut aussi être interprété par un test comme une réponse réussie. Le projet recommande un mode de blocage de type NXDOMAIN ou NULL.

Pour couvrir les hôtes, les scripts et les éléments de page, combinez selon vos besoins un filtrage DNS et une extension de navigateur. Aucun outil ne garantit un score parfait sur tous les sites.
